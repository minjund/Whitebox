## Included changes

- Combine the terminal lifecycle/input/performance fixes with the separate analysis branch `codex/answer-first-analysis` (3a286e6416aead4b5f194c99ad42327240a59aa3). Both branches share the published base. All other local feature branches are already ancestors of origin/main; the older dirty primary checkout is preserved.
- Close exact same-panel terminal panes through CLI/MCP and the pane X button. Trash remains explicit. Restore feedback appears immediately, metadata checks avoid replay downloads, and restore retains identity and history on failure.
- Show source-owned per-terminal AI token totals beside the title and a small sidebar badge only for observed active background work. Unknown counts remain unknown; finished/stale/foreign work does not create a badge.
- Repair delayed paste-menu cleanup that hides a focused Korean IME input anchor. Keep focus/selection and dispose observers safely. Physical Windows/macOS keyboard IME coverage is not inferred from Chromium/CDP checks.
- Exclude internal compaction envelopes from requests, analysis cards and caches. Recover malformed review JSON once from original evidence while preserving prior good results and stale/process identity guards.
- Generate compact, self-contained answers with visible limits, source-backed outputs and a usable next request. Preserve archived analysis overlays without copying private profile data into Git or replaying original operations. Valid compact answers do not trigger an unused legacy-decision repair.
- Cache immutable replay JSON encoding within the existing 64 MiB store budget, retaining exact bytes, atomic writes and durability acknowledgements. On an isolated copy of 83 installed sessions (~57 MB), median create latency changed 902→67 ms and close 440→37 ms; mandatory write counts stay 4/2. These are local fixture measurements, not a guarantee for every machine.

Version metadata advances to 2.0.16. Previous fixed Windows and both Mac source pins advance to official 2.0.15; all prior sources remain. Updater/helper algorithms, app identity, profile paths and store schema stay unchanged.
