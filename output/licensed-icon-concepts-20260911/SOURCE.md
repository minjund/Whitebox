Modifications: add three work-item rows, fill the status indicator green, set the
frame to charcoal, and add an off-white rounded background. No AI-generated bitmap
or Dropbox artwork was used as an input.

Intended meaning: a monitor gathers several work items, while the green indicator
shows live activity. This is a design preview, not a trademark-clearance claim.
