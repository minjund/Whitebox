# 스케치 010: 이해 패킷 배치

## 디자인 질문

완료된 메인 노드의 PTY 집중 모드에 처음 들어갈 때, 전체 작업 설명·근거와 최대 5개의 문제를 어떤 공간에 띄워야 터미널 문맥과 이해 확인의 중요성을 모두 보존할 수 있는가?

## 보는 방법

`.planning/sketches/010-comprehension-packet-placement/index.html`을 브라우저에서 연다.

## 변형

- **A: 중앙 이해 브리핑** — PTY를 어둡게 남기고 설명과 문제를 좌우 2열 모달로 표시한다.
- **B: 오른쪽 근거 시트** — PTY 왼쪽을 계속 보이게 하고 오른쪽 시트에서 오픈북 문제를 푼다.
- **C: PTY 하단 시트** — 터미널 내부에서 아래쪽 시트가 올라와 현재 작업과의 공간적 연결을 강조한다.

## 동작하는 항목

- A/B/C 배치 전환
- 전체 문항 일괄 제출과 미응답 검증
- 오답 문항만 해설·근거·미리 생성된 변형 문제로 전환
- 변형 문제 정답의 최종 점수 반영
- 재오답 후 `이해했음` 처리와 오답 점수 보존
- `문제 오류` 문항의 점수 분모·이해 부채 제외
- 닫기, 노드 귀속 이해 부채 배지, 다시 열기, 상태 초기화
- 어두운/밝은 테마와 375/768/전체 폭, 설계 주석 전환

## 무엇을 찾아봐야 할 것

- 설명을 읽고 문제를 오가기가 가장 쉬운 안은 무엇인가?
- PTY가 배경 근거로 느껴지는가, 단순히 가려진 화면처럼 느껴지는가?
- 다섯 문항으로 늘어났을 때도 제출 버튼과 현재 상태를 잃지 않는가?
- 이해 확인이 강제 시험이 아니라 다음 루프를 위한 짧은 브리핑으로 느껴지는가?
