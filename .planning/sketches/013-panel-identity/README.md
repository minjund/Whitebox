# 패널 구분 스케치

사용자 요청(2026-11-20): 섞인 분할 화면에서 터미널이 어디 소속인지 분명히 보이게. **패널 단위가 프로젝트 단위보다 중요**하다고 결정함.

- Branch: `claude/panel-identity-sketch` (base `main` `d82849e`)
- Scope: HTML 스케치만. 제품 코드는 바꾸지 않음.

## 보는 방법

`index.html`을 브라우저에서 연다. 빌드나 설치는 필요 없다. 위 버튼으로 안·상황·테마를 바꾼다.
주소 뒤에 `#<안>-<상황>-<테마>`를 붙이면 바로 그 상태로 열린다 (예: `#B-stress-dark`).

## 지금 상태 (코드 근거)

- 새 패널 이름은 모두 `패널`이라 글자로는 구분이 안 된다 (`renderer/terminal-workspace.js:1010`, `:1326`, `:2326`).
- 터미널 머리의 패널 이름표 `.wb-pane-panel`은 2.0.6(`51d6399`)부터 항상 숨김 (`renderer/terminal-workspace.js:742-745`). 패널과 터미널을 잇는 건 테두리 색뿐이다.
- 패널 박스는 "anonymous panel boxes"로 승인된 디자인이다 (`renderer/styles-workspace-clean.css`).
- 8색을 다 쓰면 채도·밝기가 같은 hsl 색을 만든다 (`renderer/terminal-workspace.js:494-495`). 9번째, 10번째 색이 1번, 8번 색과 거의 같다.
- 분할 화면이면 회색 프로젝트 이름이 모든 터미널에 붙는다. 한 프로젝트만 있어도 붙는다 (`renderer/terminal-workspace.js:733-751`).

## 안

| 안 | 모양 | 장점 | 주의 |
|---|---|---|---|
| 지금 | 테두리 색 + 회색 프로젝트 이름 | 변경 없음 | 패널을 색으로만 구분. 색이 겹치면 구분 불가 |
| A · 패널 이름표 (추천) | 머리 맨 앞에 색 막대 + `패널 N`. 사이드바 패널 박스에도 같은 이름 | 색이 비슷해도 글자로 구분. 상단 경로도 `패널 N / 터미널` | 승인된 "이름 없는 패널" 디자인을 바꿈. 번호는 패널을 만든 순서로 고정해야 함 |
| B · 이름 없이 색 머리 | 머리 배경을 패널 색으로 물들임. 사이드바 박스도 같은 색으로 | 이름 없는 디자인 유지, 색이 훨씬 넓게 보임 | 패널 10개 장면처럼 색이 겹치면 여전히 구분 불가 |

공통 제안:
- 프로젝트·브랜치는 머리 오른쪽에 작게. 화면에 서로 다른 프로젝트가 있을 때만 보인다.
- 터미널이나 사이드바 패널에 마우스를 올리면 짝이 함께 밝아진다.

브랜치 값은 가상 데이터다. 실제로는 1단계에서 프로젝트 폴더의 `.git/HEAD`를 읽는다.

## 결정 (2026-11-23)

사용자가 **B안**을 골랐다. 실제 앱 화면에 입혀 비교한 사진(repro-check 캡처)을 보고 정했다.
`index.html`은 실제 디자인과 달라서 참고용으로만 남긴다.

반영한 것:
- 터미널 머리 배경을 패널 색으로 물들인다. 선택한 터미널은 조금 더 진하다.
- 사이드바 패널 박스도 같은 색으로 옅게 물들인다.
- 상단 경로는 `[패널 색] 프로젝트 / 선택한 터미널`.
- 프로젝트 이름은 화면에 서로 다른 프로젝트가 섞였을 때만 머리 오른쪽에 작게 보인다.

넣지 않은 것: 패널 이름표·번호(A안), 브랜치 표시, 마우스를 올리면 짝이 밝아지는 동작.
